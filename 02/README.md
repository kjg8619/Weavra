## Problem and change
Layer values, transition declarations and repeated colour/shadow literals were scattered across the shared primitives and feature overlays (toast `9999-var(--toast-index)`, viewport 100, primitive 130/140, dialog 50, inspector 100-120; `transition-all` on the update pill, sheet, sidebar, primary actions and zoom indicator; literal preview separator/shadow, popup shadows and annotation fallbacks). This PR documents the contract in `apps/web/DESIGN.md` (eight sections), defines the layer, motion and material roles once in `src/index.css`, maps every listed portal and pane-local stacking context onto those roles, lists compositor properties only on the W-28 transition sites (layout snaps), lifts the audited literals onto roles, and establishes the dependency-free Korean catalog `src/i18n/ko.ts` (namespaces and common terms only; no W-03 claim). Notification delivery policy is unchanged.
