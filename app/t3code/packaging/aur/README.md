# AUR packaging unavailable

Weavra has no independent AUR package or hosted release artifacts. The historical package paths are retained but refuse before downloading, building, or publishing an upstream application. Do not execute or promote the nested historical publish-aur workflow as a Weavra release process.

Local desktop artifacts remain available through the app's existing dist:desktop:* commands. Those commands retain their lockfile, native dependency, architecture, signing, and payload validation gates. They do not authorize publication.
